Documentação Sentinel DNS

Início Instalação ISO Suporte Especializado

O Unbound Sentinel v2.6.0 é distribuído como uma imagem ISO remasterizada e pronta para implantação em servidores físicos ou máquinas virtuais (VMware, Proxmox, Hyper-V). Ele elimina 100% a necessidade de configuração manual ou conexão com a internet durante a instalação do cliente.

Appliance Sentinel (Rocky Linux 9.7)

  • Instalação 100% Offline (Unattended): O instalador automatizado via Kickstart (ks.cfg) configura particionamento, Unbound, Redis, Node.js e o painel Sentinel de forma autônoma.
  • Dynamic ISP Auto-Tuning: Motor inteligente que mede CPU e RAM no boot, ajustando limites de cache (até 4GB) e buffers UDP do kernel (até 16MB) de acordo com o hardware.
  • Hardening de Segurança: Serviço SSH padrão desativado e transferido para porta de alta tolerância contra força bruta, com regras de Firewalld ativas.
  • Hyperlocal & DNSSEC de Fábrica: Validação criptográfica ativa e resolução local de servidores raiz em 0 milissegundos via zona raiz offline pré-carregada na ISO.
  • Serve-Expired & Prefetch: Resiliência extrema. O Unbound renova domínios em background e continua servindo registros do cache por até 24h caso servidores mundiais sofram DDoS.

Recomendações de Otimização (Virtualização)

  • Proxmox/KVM: Configure a CPU como host em vez de kvm64 para acelerar cálculos do DNSSEC.
  • Placa de Rede: Utilize sempre a interface VirtIO para eliminar latências UDP.
  • Clock: Para DNS recursivo de alta concorrência, o clock do núcleo (GHz) importa mais que a quantidade.

Sentinel DNS vs Soluções Manuais (Unbound + Pi-hole)

Muitos administradores de rede tentam obter a performance e a segurança ideais combinando manualmente o Unbound DNS com filtros de rede como o Pi-hole ou AdGuard Home. Veja um comparativo de por que o Appliance Sentinel DNS é o melhor resolvedor DNS recursivo local pronto para o seu provedor de internet ou rede corporativa:

Recurso Instalação Manual (Unbound + Pi-hole) Appliance Sentinel DNS (ISO Rocky Linux)
Instalação Manual, requer digitação de dezenas de comandos no terminal e dependência de repositórios online no cliente. 100% Offline e Automática via ISO Appliance Kickstart em apenas 5 minutos.
Auto-Tuning Exige cálculo manual e complexo de Slabs, Threads e buffers de cache no arquivo de configuração do Unbound. Dynamic Auto-Tuning que mede a CPU e RAM no boot e ajusta os limites do cache e buffers UDP do kernel.
Resiliência de Rede Instável se não configurado com tags de expiração avançadas. Sem renovação preditiva automatizada. Serve-Expired e Prefetch ativos por padrão. Mantém o cache por até 24h em quedas globais do DNS.
Persistência de Cache Reinicializações do servidor limpam a memória RAM, causando lentidão de navegação temporária na rede. Persistent Cache que salva o cache em disco ao reiniciar e o recarrega na RAM instantaneamente no boot.
Telemetria NOC Gráficos simples. Exige instalação de ferramentas extras para telemetria de latência, jitter e perda de pacotes. CTI Holographic 3D Globe e Sparklines de latência integrados nativamente no dashboard.
